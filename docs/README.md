# Project Documentation

This folder tracks what was built and why for the club website.

## Documents

- `CHANGELOG.md`: timeline-style summary of major delivered changes.
- `IMPLEMENTATION_NOTES.md`: design/system notes and key technical decisions.
- `PAGES_OVERVIEW.md`: route-by-route summary of current page purpose and structure.

## Current Theme

- Dark modern layout with emerald accent.
- Primary brand accent: `#00ab55`.
- Fixed top navbar with centered navigation and right-side social icons.
- Dedicated app scroll container below navbar with custom themed scrollbar.
